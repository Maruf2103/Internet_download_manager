# Flow 1.1.0 for Windows x64

Download Flow-1.1.0-Windows-x64.zip, choose Extract All, and run Install Flow.cmd.
Python is bundled. No administrator access or Python installation is required.
Flow.cmd runs the portable version.

The adjacent .zip.sha256 file contains the archive checksum. Application source
and build instructions are on the main branch. The application and browser
checks passed on Linux; native Windows verification is handled separately by CI.
