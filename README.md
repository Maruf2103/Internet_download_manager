# Flow 2.0 for Windows x64

Download Flow-2.0.0-Windows-x64.zip, choose Extract All, and run Install Flow.cmd.
Python and the Chrome extension are bundled. No administrator access or separate
Python installation is required.

Features: any HTTP(S) file type, app installers, public folder trees, JSON manifests,
resumable segmented transfers with up to 16 connections per file, and Chrome integration.

Computer setup guide: https://github.com/Maruf2103/Internet_download_manager/blob/main/docs/WINDOWS-SETUP.md
Chrome setup: install Flow, then load the installed ChromeExtension folder using
Developer mode at chrome://extensions. Multiple Wi-Fi bonding is not included.

SHA-256 checksums are beside the ZIPs. Prior version 1.1 remains available here.
