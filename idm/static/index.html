    Flow, right in Chrome.

    1. Install the Windows update and restart Chrome.
    2. Open chrome://extensions and switch on Developer mode.
    3. Choose Load unpacked, then select:
      %LOCALAPPDATA%\Programs\Flow\2.0.0\ChromeExtension
    4. Pin Flow to your toolbar. The popup should show “bridge is ready”.
    5. Right-click a file link → Download link with Flow.

    Automatic download handoff is optional. Direct files of any type work; login-protected downloads and DRM media may need Chrome. No Wi-Fi bonding or guaranteed speed multiplier is claimed.
